# Personal Portfolio Website

A clean, modern, responsive personal portfolio built with semantic HTML5 and custom CSS. 

## 🚀 Live Demo
- View the live site: [My Portfolio](https://arjun0729.github.io/my-portfolio/)

## 🛠️ Built With
- **HTML5**: Semantic document structure
- **CSS3**: Modern Flexbox, CSS variables, and subtle hover animations
- **Git & GitHub Desktop**: Checkpoint-based version control
- **GitHub Pages**: Automated cloud deployment

## 🎯 Features
- Responsive layout adapting to desktop and mobile screen sizes
- Interactive project showcase cards
- Direct contact and external profile links
